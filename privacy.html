プライバシーポリシー

最終更新日: 2026年7月21日

Soundic（以下「本サービス」）は、ユーザーのプライバシーを尊重し、個人情報の適切な取扱いに努めます。本ポリシーは、本サービスがどのような情報を収集し、どのように利用・保護するかを定めます。

1. 収集する情報

本サービスは、以下の情報を収集します。

1.1 ユーザーから提供される情報

  • アカウント情報: メールアドレス、表示名、ユーザー名、プロフィール画像
  • 投稿コンテンツ: チェックイン（位置情報・楽曲情報・写真・動画・キャプション・「なんでこの曲？」テキスト）、プレイリスト、コメント、いいね、チーム内のメッセージ、ダイレクトメッセージ

1.2 自動的に収集される情報

  • 位置情報: チェックイン時の緯度経度（プライバシー保護のため、スポット表示時は半径1km程度に丸めて表示）
  • 再生履歴: 楽曲タイトル、アーティスト、再生時刻、再生元（チャート/プレイリスト等）。再生履歴は、ランキングやおすすめ楽曲の集計のため、他のユーザーにも集計・関連情報として反映されることがあります。
  • デバイス情報: 端末種別、OS、アプリバージョン

2. 利用目的

収集した情報は、以下の目的で利用します。

1. 本サービスの提供・運営・改善

2. ユーザーの認証・本人確認

3. 投稿の表示、フォロー関係・通知の処理

4. 「バイブスポイント」「スポットランキング」「おすすめ楽曲」等の機能提供

5. 不正利用の防止、安全な運営

6. お問い合わせへの対応

7. 利用規約違反への対処

3. 第三者への提供

本サービスは、原則として第三者にユーザーの個人情報を提供しません。ただし、以下の場合を除きます。

  • ユーザーの同意がある場合
  • 法令に基づく場合
  • 人の生命・身体または財産の保護のために必要な場合

4. 業務委託・データの保管場所

本サービスは、データベース・認証・ストレージ機能の提供のため、以下の海外事業者を利用しています。

  • Supabase, Inc.（米国）: データベース、認証、ストレージ
  • Apple Inc.（米国）: Apple Music（MusicKit）による楽曲再生、Apple Music API / iTunes Search API による楽曲メタデータ・チャート
  • Google LLC（米国）: Gemini API によるおすすめ・ニュース文章の生成（送信されるのは気分・地域・最近の再生曲名などの最小限の情報で、氏名やメールアドレスは送信しません）

これらの事業者には、本サービスの運営に必要な範囲内でのみ情報が提供されます。

5. ユーザーの権利

ユーザーは、自己の個人情報について以下の権利を有します。

  • アクセス権: 保有する個人情報の開示を求める権利
  • 訂正権: 不正確な情報の訂正を求める権利
  • 削除権: アカウント削除により、自己の個人情報の削除を求める権利
  • 利用停止権: 一定の場合に利用停止を求める権利

アカウント削除は、アプリ内の「設定 → アカウント削除」から行えます。削除リクエスト後、関連するすべての投稿・プレイリスト・履歴データが完全に削除されます。

6. データの保存期間

  • アクティブなアカウントの情報: アカウント存続中
  • 削除後: 削除リクエスト受領後速やかに完全削除（バックアップから消去されるまで最大30日）

7. 安全管理措置

本サービスは、収集した情報の漏洩、滅失、毀損を防止するため、以下の措置を講じます。

  • すべての通信を TLS 1.2 以上で暗号化
  • データベースに行レベルセキュリティ（RLS）を適用
  • パスワードは Supabase 認証によりハッシュ化して保管

8. クッキー・トラッキング

本サービスはアプリ内でクッキーやサードパーティ広告トラッカーを使用しません。

9. 16歳未満の利用

本サービスは16歳以上を対象としています。16歳未満の方は本サービスを利用できません。

10. ポリシーの変更

本ポリシーは予告なく変更されることがあります。重要な変更がある場合は、アプリ内で通知します。
